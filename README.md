# Electrician Leads Agent

תכנון סוכן AI — מטלה 6, קורס AiDO (שיעור 6: AI Agents).

הסוכן קורא פורום ישראלי של חשמלאים, ומוציא ממנו שני דברים:

1. **לידים** — חשמלאי שנתקל בקושי שכלי התמחור שלי פותר: תמחור עבודה, הכנת הצעת
   מחיר, או חישוב עלות חומרים.
2. **כיול מחירים** — מחירים אמיתיים שאנשים מציינים בפורום, מול המחירון של כלי
   התמחור שלי, כדי לראות מתי המחירון שלי חורג מהשוק.

שני הפלטים נכתבים כשורות ב-Airtable, שהוא מקור הנתונים שכלי התמחור כבר קורא ממנו.

הסוכן לא מפרסם בפורום ולא שומר פרטי קשר של אף אחד. ליד הוא מחקר שוק, לא רשימת
אנשים לפנות אליהם.

## מה השתנה אחרי שבדקתי את המקור

את הגרסה הראשונה כתבתי לפי הנחות. אחרי שבדקתי את הפורום בפועל התברר שהקהל שם הוא
חשמלאים ולא בעלי בתים, שהפורום פעיל הרבה יותר ממה שהנחתי, ושמנגנון הזיכרון
שתכננתי לא עובד כי הרשימה ממוינת לפי פעילות אחרונה ולא לפי תאריך יצירה. פרק 0
ב-SPEC מפרט את ארבעת התיקונים.

## המסמכים

- למה סוכן ולא תרחיש Make

- מה קורה עם הפלט, ומי מחליט מה לעשות איתו
- גבול האמון: הקלט נכתב על ידי זרים, ושלוש שכבות הגנה
